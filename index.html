FEATURES

Version hopping without folder chaos.

Separate instances

Every version gets its own folder so one install does not overwrite another.

Saved manifests

Brickum keeps manifest IDs in brickum_history.json so old versions are not forgotten.

DepotDownloader

Brickum uses DepotDownloader for Steam depot downloads instead of scraping SteamDB.

Verified installs

A download stays in a partial folder until Brickum finds BrickRigs.exe.

HOW IT WORKS

Pick. Download. Launch.

  1. 01

    Choose a depot and manifest

    Pick the Brick Rigs build you want to install.

  2. 02

    Brickum downloads it

    The game first downloads into a staging folder.

  3. 03

    Brickum prepares the instance

    It creates steam_appid.txt containing 552100 and saves instance info.

  4. 04

    Run BrickRigs.exe

    Launch that exact version from its own instance.
